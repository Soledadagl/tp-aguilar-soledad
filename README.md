
# Explorador de episodios - Rick and Morty

**Autora:** Soledad Aguilar  
**Carrera:** Ingeniería en Informática  
**Asignatura:** Fundamentos de Desarrollo Web  
**Variante:** C - Episodios

## Descripción

Este proyecto es una página web que permite buscar episodios de Rick and Morty por nombre y temporada.

Utiliza HTML semántico, CSS Grid, Flexbox y JavaScript para consultar una API REST, mostrar resultados en tarjetas y recordar la última búsqueda mediante localStorage.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript ES6+
- Fetch API y async/await
- Rick and Morty API
- GitHub Pages
